# 🚀 TeamFlow

TeamFlow is a modern, full-stack MERN (MongoDB, Express, React, Node.js) workspace collaboration application designed for teams to manage tasks, collaborate in real-time via Socket.io chat, and invite members seamlessly.

![TeamFlow Dashboard Preview](https://img.shields.io/badge/Status-Live%20%26%20Operational-success)
![Tech Stack](https://img.shields.io/badge/Tech%20Stack-MERN%20%2B%20TailwindCSS-blue)

---

## ✨ Features

- **User Authentication**: Secure JWT-based registration and login flow.
- **Workspace Management**: Create, view, and organize team workspaces dynamically.
- **Task Management**: Create tasks, assign details, and track progress across states (*Todo, In Progress, Done*).
- **Real-Time Chat & Activity**: Instant messaging powered by **Socket.io** with live online user counters.
- **Team Invitations**: Invite registered users to join your workspaces by email.
- **Responsive UI**: Sleek, modern dark-mode interface styled with **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Frontend**: React, React Router, Tailwind CSS, Socket.io-client
- **Backend**: Node.js, Express.js, Socket.io, JSON Web Tokens (JWT)
- **Database**: MongoDB & Mongoose
- **Deployment**: Vercel (Frontend) & Render (Backend)
